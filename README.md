# Grace

Grace is a soft, personalized AI-powered personal life companion.

The goal of Grace is to understand the user, their preferences, interests,
hobbies, and context, and bring that understanding into different parts of
their personal experience.

## Project Status

🚧 Foundation stage — development has just started.

## Core Areas

- Onboarding
- Personal AI Companion
- Personal Dashboard
- Health Monitor
- Adaptive Hobbies
- Notes
- Create
- Music
- Profile
- Settings

## Visual Direction

Grace is designed to feel:

- Soft
- Cute
- Warm
- Calm
- Human
- Personal

The visual system is inspired by sunrise and sunset colors rather than a
futuristic or overly technical aesthetic.

## Development

Grace is being built incrementally, starting with the project foundation,
architecture, and development environment before implementing features.
